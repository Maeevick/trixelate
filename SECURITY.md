# Security policy

## Supported versions

trixelate is kept by one person, so only the most recent release gets security fixes.

| Version | Supported |
| --- | --- |
| The most recent release | :white_check_mark: |
| Any older release | :x: |

## Reporting a vulnerability

Report it privately on GitHub, from the repository's Security tab: [report a vulnerability](https://github.com/Maeevick/trixelate/security/advisories/new). Please don't open a public issue for it.

Say what you found, how to reproduce it (a crafted picture is welcome), and what it lets someone do.

- You get a first answer within 7 days.
- An accepted report is fixed in a release, published as a GitHub security advisory, and credited to you unless you'd rather not.
- A declined report gets its reasons.

The library, the command line and the page all read untrusted pictures. A crash, runaway memory or time, a file written where it shouldn't be, or anything that sends a picture out of the browser is in scope.
